# Pick Block Pro — 功能文档

> 高级客户端侧方块 / 实体 / NBT / 工具 / ID 拾取器
> 纯客户端模组，不影响服务端，无需服务端安装。

---

## 1. 概述

Pick Block Pro（下称 PBP）扩展了 Minecraft 原版的中键拾取与工具选择能力：

- **拿得更准**：原版中键只能给你一个「大概对应」的物品；PBP 能把方块状态、方块实体数据、实体 NBT 一并带出来。
- **拿得更全**：能识别画作、物品框、下落方块、玩家头颅，以及太阳/月亮这类光源方块。
- **给得更准**：自动挑出当前目标的最优工具 / 武器，按附魔收益和耐久打分，而不是「有没有对应工具」。
- **看得更清**：一键复制方块 / 实体 / 物品的 ID 与 NBT，可直接粘到命令或文档里。

---

## 2. 区块拾取（Block Picker）

中键拾取，但完全接管了原版行为。

### 2.1 拾取目标

| 目标 | 结果 |
|---|---|
| 普通方块 | 对应物品 |
| 流体方块 | 对应材质的桶（而非水流/岩浆方块本身） |
| 实体 | 该实体的拾取物品（如僵尸 → 僵尸头） |
| 下落中的方块 | 该方块的物品（而不是空气） |
| 玩家 | 玩家头颅，带有对应头颅皮肤 |
| 太阳 / 月亮 | 对应的光源方块物品 |

### 2.2 修饰键增强

| 按键 | 效果 |
|---|---|
| **Ctrl + 拾取实体** | 额外附加实体的完整 NBT 数据 |
| **Ctrl + 拾取物品框** | 物品框物品，并把「框内物品名」写进物品的自定义名称 |
| **Ctrl + 拾取画作** | 画作物品，并把「画作标题」写进物品的自定义名称 |
| **Ctrl + 拾取方块** | 额外附加方块实体的完整数据（如箱子内容、告示牌文字、头颅信息） |
| **Alt + 拾取方块** | 额外附加方块的完整状态属性（如朝向、台阶朝向、开关状态） |
| **Alt + 拾取下落方块** | 额外附加该下落方块的状态属性 |

> 拾取范围可独立设置（区块 / 实体分别配置），也可选择沿用玩家自身的交互距离。

### 2.3 拾取范围

- 区块拾取范围与实体拾取范围分别可配
- 可选择使用「玩家交互距离」而非固定值
- 创造模式可单独使用更大的范围

## 3. ID 拾取（ID Picker）

把目标的标识信息直接输出到聊天栏，并可一键复制。

### 3.1 输出内容

| 目标 | 默认输出 | Ctrl 切换后 |
|---|---|---|
| 方块 | 方块 ID（可带命名空间）+ 方块状态属性 | 方块实体的完整 NBT |
| 实体 | 实体 ID（可带命名空间） | 实体的完整 NBT |
| 物品 | 物品 ID | — |

### 3.2 可配置项

- **是否带命名空间**：输出 `minecraft:stone` 还是只输出 `stone`
- **是否附带状态属性**：把 `facing=north`、`half=top` 这类属性一并列出
- **是否复制到剪贴板**：复制的同时仍会显示在聊天栏
- **NBT 标签黑名单**：逐条屏蔽不想显示的 NBT 键（例如实体里的 UUID、坐标、朝向）
- **属性黑名单**：逐条屏蔽不想显示的方块状态属性（例如 `waterlogged`）
- **NBT 美化输出**：以缩进格式而非单行输出，便于阅读
- **物品转方块 ID**：把桶、墙等特殊物品的 ID 转成其对应方块的 ID

### 3.3 聊天框内快捷输出

在聊天输入框打开时，按 **Ctrl + 数字键（1-9 或 0）**，直接把对应快捷栏槽位物品的 ID 写入输入框，无需手动输入。

---

## 4. 工具拾取（Tool Picker）

自动为当前目标选择或生成最合适的工具 / 武器。

### 4.1 选工具

看向一个方块，PBP 会：

- 在你的背包里找出所有能处理该方块的物品
- 按综合评分挑出最优的一个并切换到对应槽位
- 若背包里**一件都没有**，会提示（生存模式不会凭空生成物品）

**评分维度**：

- 工具本身的挖掘速度
- 工具耐久上限（耐久的工具更耐用）
- 精准采集 / 时运（按配置项分别加权）
- 效率
- 耐久 / 经验修补
- 耐久剩余量：低于设定阈值的工具会被跳过

### 4.2 特殊判定

- **剪刀**：能剪的方块有专门列表（蛛网、藤蔓、洞穴藤蔓、垂根、草丛、蕨类、发光苔藓、海草等）
- **竹子**：默认优先用剑（可关闭）
- **刷子**：考古类方块（可疑的沙雕、疑似涂鸦的箱子等）自动配刷子
- **桶**：液体方块与粉雪自动配桶
- **镐 / 斧 / 锹 / 锄**：按方块的挖掘标签自动匹配

### 4.3 选武器

看向一个生物时，自动挑出最优武器：

- 以武器的**基础攻击伤害**为主分
- 计入附魔带来的额外伤害（如亡灵杀手对亡灵、生物亲和带来的目标加成）
- 支持**弓 / 三叉戟偏好列表**：指定哪些生物优先用弓（可通过潜影贝实体等手段获取），哪些优先用三叉戟

### 4.4 生存 / 创造模式差异

| | 生存模式 | 创造模式 |
|---|---|---|
| 行为 | 从背包里**选**已有的最佳工具 | 直接**生成**一件带满附魔的工具 / 武器 |
| 背包里没有 | 提示无可用工具 | 直接发放 |
| 耐久不足 | 跳过并提示 | 不受影响 |

## 5. 附魔与配置

### 5.1 每件工具 / 武器独立配置

每种工具与武器都可单独配置：使用哪件物品、各级附魔的等级与开关。

**工具**（9 种）：镐、斧、锹、锄、剑、剪刀、桶、钓鱼竿、刷子
**武器**（6 种）：剑、斧、弓、弩、三叉戟、锤

### 5.2 附魔冲突自动处理

PBP 会根据目标自动剔除互相冲突的附魔：

- 亡灵杀手 ↔ 尖刺 / 虫杀手 / 破甲 / 密度
- 虫杀手 ↔ 尖刺 / 亡灵杀手 / 破甲 / 密度
- 精准采集 ↔ 时运（可配置哪个优先）
- 无限 ↔ 经验修补
- 多重射击 ↔ 穿透
- 激流 ↔ -channeling / 忠诚

### 5.3 附魔加权偏好

可分别设置：是否优先精准采集、是否优先效率。不同偏好的工具会在评分里拿到不同的加成。

### 5.4 不兼容附魔模式

默认会剔除冲突附魔；也可开启「允许不兼容附魔」，此时按配置的最高等级原样生成（最高 255 级）。

---

## 6. 创造模式物品栏注入

把配置好的附魔工具 / 武器注入到创造模式物品栏中，方便随时取用。

- 工具与武器分别开关
- 武器与工具有重叠项（如斧）时不会重复添加
- 默认注入「运营者」分类

---

## 7. 背包管理

PBP 自己管理物品的放置位置，而不是丢给原版。

### 7.1 选槽位逻辑

1. 物品**已在快捷栏** → 直接切到那个槽位
2. 物品**在背包里**（生存模式还会翻找潜影盒 / 收纳袋）→ 与当前手持物品交换到快捷栏
3. **都不在** → 找一个空位 / 未锁定的快捷栏槽位放进去

### 7.2 锁定槽位

快捷栏 1-9 可逐个锁定，锁定后 PBP 不会占用或切换这些槽位。

### 7.3 其他

- **保持在原槽位**：切换物品后切回原来的槽位（仅在两个槽位都未被锁定时生效）
- **搜索容器**：生存模式下会翻找潜影盒、收纳袋等容器，看里面有没有目标物品，有就直接切到那个容器所在槽位
- 所有背包改动都会**与服务器同步**，不会因客户端预测而回弹

## 8. 命令

| 命令 | 作用 |
|---|---|
| `/pbp reload` | 重新载入自定义映射文件（无需重启游戏） |
| `/pbp give <工具>` | 获得一件带满配置附魔的工具 |
| `/pbp give <武器>` | 获得一件带满配置附魔的武器 |

`/pbp give` 可用的名称：pickaxe、axe、shovel、hoe、sword、shears、bucket、fishing_rod、brush、bow、crossbow、trident、mace。

---

## 9. 自定义映射（overrides.json）

在配置文件里可以强制指定「某个方块 / 实体 → 某个物品」，覆盖默认拾取结果。

- **Block to ItemStack**：方块 ID → 物品 ID（可带 `[组件]` 语法）
- **Entity to ItemStack**：实体 ID → 物品 ID（可带 `[组件]` 语法）

例：让「铁块」总是拾取成「铁锭」，让「猪」总是拾取成「猪排」。

支持原版物品 ID 语法，包括 `minecraft:xxx[custom_data={...}]` 这类组件写法。

## 10. 配置界面

通过 **Mod Menu** 打开，界面由 **Cloth Config** 渲染。分组如下：

| 分组 | 内容 |
|---|---|
| **区块拾取** | 拾取范围、交互距离开关、创造模式范围、是否拾取方块 / 实体 / 流体 / 光源、是否接管 Litematica、方块状态与方块实体与实体的 NBT 黑名单 |
| **ID 拾取** | 拾取范围、交互距离开关、拾取对象、命名空间、状态属性、剪贴板、聊天框快捷输出、物品转方块、NBT 开关与美化、各类黑名单 |
| **工具拾取** | 拾取范围、交互距离开关、耐久阈值、是否拾取流体、附魔偏好、冲突处理、工具与武器的逐项配置 |
| **背包** | 是否搜索容器、是否保持原槽位、快捷栏 1-9 的锁定开关 |

附魔字段的标签会自动复用 Minecraft 原版附魔的翻译（如 `silk_touch` 显示为「精准采集」），无需为每个附魔重复写翻译。

## 11. 兼容性

| 模组 | 关系 | 作用 |
|---|---|---|
| **Litematica** | 可选 | 接管其自带的 Pick Block，改用 PBP 的拾取距离、修饰键逻辑与背包管理，避免两个模组的拾取行为打架 |
| **Mod Menu** | 可选 | 提供配置界面入口 |
| **Cloth Config** | 必需 | 配置界面渲染 |
| **inventory_control_tweaks** | 建议 | 与其背包锁定功能配合 |

## 13. 适用场景速查

| 你想做的事 | 用什么 |
|---|---|
| 快速拿到一个楼梯方块 | 中键拾取（带朝向信息） |
| 复制一个箱子的内容 | Ctrl + 中键拾取箱子 |
| 复制某个生物的完整 NBT | Ctrl + 中键拾取生物 |
| 拿一个箱子里的潜影盒内容 | 中键拾取潜影盒 → Ctrl 复制 NBT |
| 查某个方块的状态值 | ID 拾取 |
| 复制物品 ID 到命令框 | 聊天框内 Ctrl + 数字键 |
| 找一把挖黑曜石最快的镐 | 中键看向黑曜石（生存模式自动切换） |
| 造一把满附魔的效率 V 镐 | 创造模式 + 工具拾取，或 `/pbp give pickaxe` |
| 对付一群骷髅 | 看向骷髅，让 PBP 挑亡灵杀手武器 |
